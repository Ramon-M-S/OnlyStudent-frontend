# OnlyStudent Frontend

## Executar

```bash
npm install
npm run dev
npm run test:unit
npm run build
```

**Atenção:** Esta versão é um scaffold demonstrativo, não a aplicação completa do repositório original Ramon-M-S/OnlyStudent-frontend. A autenticação, dashboards reais, materiais e integração ao backend Spring Boot ainda precisam ser migrados e conectados. Os indicadores no mock de dashboard são ilustrativos. Não confunda a interface demonstrativa com dados reais.
