# OnlyStudent Frontend

Primeira versão visual independente em **Vue 3 + Vite**, inspirada em interfaces de produtividade (Linear, Vercel, Notion e Raycast).

## Executar

```bash
npm install
npm run dev
npm run test:unit
npm run build
```

## Escopo

- Landing page responsiva, acessível, tema claro/escuro, mock de painel.
- Testes unitários automatizados com Vitest + Vue Test Utils.
- GitHub Actions para testes e build.

**Atenção:** Este repositório estava vazio (apenas LICENSE) quando a implementação foi enviada. Esta versão é um scaffold demonstrativo, não a aplicação completa do repositório original Ramon-M-S/OnlyStudent-frontend. A autenticação, dashboards reais, materiais e integração ao backend Spring Boot ainda precisam ser migrados e conectados. Os indicadores no mock de dashboard são ilustrativos. Não confunda a interface demonstrativa com dados reais.
